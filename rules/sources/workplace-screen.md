# User-provided workplace policy: switch off the display before departure

Policy recorded: 2026-10-18. Application reference: `/policies/workplace-screen`.

The user explicitly supplied this workplace rule: when a person leaves the workstation, its computer or laptop screen must be switched off. Leaving the workplace unattended while that display is visibly still on is a violation. This document records the user's application policy. It does not claim an independently verified employer document, a statutory requirement or a public-law citation.

Rule `workstation_departure_screen_left_on` requires a source-referenced before/departure/after sequence. The evidence must identify the computer monitor or laptop display at the operating workstation, establish the operator there before departure, show an actual departure, and show that same workstation unattended afterwards with the same identified display visibly still on. The unattended state and illuminated display must be visible together after departure. The rule does not require an active client intake, unfinished transaction, personal identity or observation of an invisible power button.

A single still of an empty chair and a bright screen can motivate review, but cannot establish that a person departed during the observed sequence. Standing, reaching within the workstation, brief occlusion and moving between work surfaces inside the same workplace are insufficient departures. A different person continuing to attend the same work desk does not establish an unattended workstation.

The screen itself must be readable enough to establish that its display remains on. An unidentified bright rectangle, reflection, glare or unresolved power state is insufficient. A locked but visibly illuminated screen is still on under this policy; the requirement concerns display power rather than session locking. A closed laptop lid, or a visibly off, black or standby screen, cannot be assumed to be on. Screen content and authentication state are not inferred.

Supported findings include source timestamps and evidence JPEGs and remain subject to human review. Unresolved departure, attendance, screen identity or power state remains unknown. Model confidence is uncalibrated; this policy record makes no claim of measured detection accuracy.
