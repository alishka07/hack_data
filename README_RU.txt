ЛОКАЛЬНАЯ ПРОВЕРКА ЗАПИСАННЫХ ВИДЕО

Рабочая папка: D:\open\case
Исходные видео: videos\

БЫСТРЫЙ ЗАПУСК

Откройте терминал в этой папке. Используется ваш глобальный Python 3.11:

    cd D:\open\case
    python start.py --video X-1.mov

Все видео с настройками по умолчанию:

    python start.py

Это то же самое, что --all --interval 1: модель проверяет примерно один
кадр в секунду. По умолчанию ищутся оборудование и пакеты.
Результат открывается файлом results\objects\index.html.

Если команда python выбирает другой Python, используйте в PowerShell:

    & "C:\Users\User\AppData\Local\Programs\Python\Python311\python.exe" start.py --video X-1.mov

В Jupyter с вашим глобальным ядром выполните в ячейке:

    %cd D:\open\case
    %run start.py --video X-1.mov

start.py запускает run.py отдельным процессом того же Python. Это важно:
уже загруженный в ядро transformers другой версии не должен мешать модели.
Для запуска из обычного терминала также можно использовать python run.py.

ОБЗОР ВСЕЙ ПАПКИ И ДОПОЛНИТЕЛЬНЫЕ ОБЪЕКТЫ

Команда обзорного прогона с шагом 5 секунд:

    python start.py --all --interval 5 --output results/all_videos_5s --resume

Результат: results\all_videos_5s\index.html.
--resume пропускает завершённые видео только при совпадении настроек,
исходного файла, фильтров и калибровки. Изменённые настройки требуют нового
анализа. Чтобы сохранить предыдущий результат, задайте другую --output.

Добавить поиск предметов на столе и банкнот:

    python start.py --video X-1.mov --groups equipment bags desk cash --output results/extended

Быстрая проверка запуска на двух выбранных кадрах:

    python start.py --video X-1.mov --max-samples 2 --output results/smoke

--max-samples ограничивает число кадров для модели, но файл всё равно
декодируется до конца. --no-video отключает создание видеопредпросмотра.
Полный список параметров: python run.py --help.

КАК ЧИТАТЬ РЕЗУЛЬТАТ

В подпапке каждого видео:
  review.mp4       — H.264-предпросмотр только выбранных кадров;
  detections.csv   — рамки, время, статус и причины фильтрации;
  frames.jsonl     — исходные ответы модели и результаты фильтров;
  summary.json    — сколько кадров прочитано и проверено моделью;
  sample_*.jpg    — первые выбранные кадры с рамками.

Зелёные рамки — кандидаты модели. Жёлтые — неоднозначные ответы, которые
нужно проверить вручную. Отсеянные ответы сохранены в таблице и JSONL.
Число рамок не равно числу уникальных предметов.

Программа читает все кадры, но нейросеть анализирует только выбранные
с указанным интервалом. Предпросмотр не заменяет исходное плавное видео.
Короткое действие между выбранными кадрами может быть пропущено.
Шаг 5 секунд подходит для обзорной проверки предметов, а не для проверки
правила двери на 3,5 секунды.

ЕСЛИ СЧЁТЧИК ПУТАЕТСЯ С ПАКЕТОМ, А РОЗЕТКА — СО СЧЁТЧИКОМ

В запросах модели добавлены альтернативы: счётчик, розетка, удлинитель,
пакет и другое оборудование. candidate_filters.py объединяет дубли одного
класса и отправляет сильно перекрывающиеся несовместимые ответы на проверку.
Высокая оценка модели сама по себе не доказывает правильность подписи.
Фильтры уменьшают часть ошибок, но не гарантируют их устранение.

Для конкретного видео можно вручную отметить известное оборудование:

    python calibrate_scene.py --video X-1.mov --second 10

В появляющихся окнах последовательно выделите прямоугольником:
  banknote_counter — настоящий счётчик банкнот;
  safe             — сейф;
  laptop           — ноутбук;
  exclude          — только розетку/удлинитель, не весь стол.
Enter подтверждает прямоугольник, C пропускает текущую область.
Если на 10-й секунде нет кадра, укажите --second 0.

exclude подавляет только ошибочные кандидаты banknote_counter внутри
выделенной области. Это не исключение всех объектов из этой части кадра.
Области оборудования помогают отмечать противоречия; сами они не создают
детекций и не переименовывают пакет в счётчик или системный блок в сейф.

Настройки сохраняются в scenes\<имя видео>.json и относятся только
к этому файлу. После разметки можно пересчитать фильтры сохранённых
результатов без повторного запуска нейросети:

    python refilter.py --results results/all_videos_5s

При изменении ракурса
или положения оборудования нужна новая разметка; движение камеры
внутри видео автоматически не компенсируется.

ПРОВЕРКА ФАЙЛОВ И ОТСЛЕЖИВАНИЕ ЛЮДЕЙ

Прочитать все кадры без нейросети, проверить параметры и сохранить обзор:

    python video_inventory.py

Результат: results\inventory\inventory.json, inventory.csv и contact_sheet_*.jpg.
Успешное декодирование не гарантирует отсутствие всех дефектов изображения.

RT-DETR + ByteTrack, отдельный запуск для людей:

    python track_people.py --video X-1.mov --start 10 --duration 5

Без --duration или с --duration 0 обрабатывается оставшаяся часть видео
от --start. По умолчанию --start равен 0. Результат — results\people\.
Номера треков могут меняться; это не идентификация личности и не точный
подсчёт уникальных клиентов. Этот запуск не объединён с объектным анализом.

ЧТО НУЖНО СОХРАНИТЬ НА ДИСКЕ

  D:\open\GroundingDINO-local\detect_local.py
  D:\open\GroundingDINO-local\weights\
  D:\open\GroundingDINO-local\compat\

Для трекинга людей дополнительно нужны соседние папки ByteTrack-main
и RT-DETR-main с уже подготовленным кодом и весами.
В compat используется проверенная здесь версия transformers 4.51.3;
глобальная установка transformers не заменяется. Отдельная виртуальная
среда не требуется. При переносе на другой ноутбук нужны также совместимые
глобальные зависимости, включая PyTorch, OpenCV, Pillow и imageio-ffmpeg.

На текущем ноутбуке видеопамять — 4 ГБ. Запускайте обработку предметов
и трекинг людей по очереди. Время зависит от устройства, длительности,
интервала и числа групп; выполнение за пять минут не гарантировано.
Инференс использует локальные веса. Эти скрипты не отправляют видео
в облако, не скачивают датасет Roboflow и не выполняют новое обучение.

ГРАНИЦЫ ТЕКУЩЕГО ПРОТОТИПА

Это поиск кандидатов в объекты, а не готовый детектор всех нарушений.
Не реализованы распознавание открытого/закрытого состояния двери и сейфа,
факт пересчёта денег, проверка удостоверения, уход клиента и проверка
порядка обслуживания. Ваш порог открытой двери — 3,5 секунды; наличие
таймера без распознавания состояния двери не позволяет проверить правило.
Этот порог здесь не представлен как подтверждённая норма законодательства.

Пакет на изображении не доказывает наличие денег внутри. Видимый документ
не доказывает его принадлежность прошлому клиенту. Отсутствие рамки
не доказывает отсутствие предмета. Сейф и мелкие предметы модель может
пропускать или путать с другими объектами. Итоговое поле verdict оставлено
как not_evaluated: заключение о нарушениях автоматически не выносится.
