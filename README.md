# Проверка записей кассы

Локальное приложение: загрузка видео, возможные нарушения с таймкодами,
просмотр скриншотов и сохранение результатов в JSON. Нажатие на эпизод
переводит непрерывное видео ко времени события. Результаты требуют проверки
человеком; система не устанавливает личность людей и не принимает кадровые решения.

## Установка на другом компьютере

Нужны **Python 3.11**, **Git** и **Git LFS**. В репозитории находятся адаптеры,
код моделей и три файла весов общим размером около **1,03 ГБ**.
Не используйте Download ZIP как замену Git LFS: внутри могут оказаться только
небольшие указатели на большие файлы.

```powershell
git lfs install
git clone https://github.com/alishka07/hack_data.git
cd hack_data
git lfs pull
py -3.11 setup_local.py
.venv\Scripts\python.exe launch_web.py
```

После установки можно запускать файл **Запустить.cmd**. Страница:
<http://127.0.0.1:8765/>. Сервер доступен только на этом компьютере.

По умолчанию устанавливается CPU-версия PyTorch. Для компьютера с подходящей
видеокартой NVIDIA вместо команды установки используйте:

```powershell
py -3.11 setup_local.py --cuda
```

Этот вариант устанавливает PyTorch с CUDA 12.1. На CPU анализ заметно медленнее.
Установщик создаёт `.venv`, проверяет SHA-256 весов и импорты адаптеров,
не меняет глобальные Python-пакеты. Интернет нужен для клонирования и установки;
модели работают с локальными весами.

Linux с Python 3.11: `python3.11 setup_local.py`, затем
`.venv/bin/python launch_web.py`. Проверка установки проведена на Windows;
Linux отдельно не проверялся.

## Работа с видео

1. Выберите файл и нажмите «Проверить нарушения».
2. Откройте результат. Нажмите на название эпизода или «Показать в видео».
   Выбирается непрерывная запись с траекториями; если она недоступна,
   используется соответствующее выборочное превью с его отдельным таймкодом.
3. Вкладка «Скриншоты» открывает галерею. Нажмите кадр для увеличения;
   используйте кнопки или стрелки клавиатуры, Escape — закрыть.
4. «Сохранить результаты · JSON» сохраняет сведения о записи, события,
   охват правил, наблюдения моделей и ограничения в одном файле.
   Изображения в JSON не встраиваются: ссылки ведут на локальные файлы.
   Для переноса кадров используйте «Другие форматы и видеокопии» → ZIP.

## Что включено

- RT-DETRv2: исходные COCO-веса для людей и локальная модель оборудования
  (сейф, счётчик банкнот, ноутбук, мешок).
- ByteTrack: трекер с локальным адаптером RT-DETR, без сборки Cython расширения.
- Grounding DINO tiny: веса, токенизатор и адаптер поиска предметов.
- Веб-интерфейс, временные правила, подготовка разметки и тесты.

Код моделей расположен внутри `runtime/`, модель оборудования — в
`models/equipment/`. Соседние папки `D:\open` и абсолютные пути конкретного
пользователя для запуска не нужны. Лицензии и изменения стороннего кода:
[THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt).

## Границы переносимости

Исходные видео, кадры людей, таблицы и персональная разметка в Git не включены.
Распознавание состояний двери/сейфа зависит от эталонов конкретной камеры.
Без локального `training/visual_states_v2/model.json` этот этап не запускается,
а соответствующие проверки остаются без оценки. Копирование весов не означает,
что модель обучена новому помещению. Сохранённые результаты и галерея разметки
из исходного проекта не переносятся; пользователь загружает собственное видео.

Порог открытой двери **3,5 секунды** — настройка кейса, не утверждение о норме НБРК.
Пачка денег не доказывает пересчёт; закрытая дверца не доказывает запирание;
карточка не подтверждает подлинность удостоверения. Экспериментальная cash-only
модель из отдельного пилота не включена: на малом отложенном наборе она оказалась
хуже Grounding DINO.

## Проверка установки и кода

```powershell
.venv\Scripts\python.exe check_install.py
.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py"
node test_review_helpers.cjs
```

Node нужен только для теста логики интерфейса. Рабочему приложению Node не нужен.
Проверки, которым нужны исключённые из Git локальные материалы кейса,
помечаются как skipped. Остальные тесты используют синтетические данные.
Старые `README_*_RU.txt` содержат историю отдельных экспериментов; актуальная
инструкция переносимого запуска — этот файл.
