АУГМЕНТАЦИЯ ОБЪЕКТОВ — С АКЦЕНТОМ НА МЕШКИ И ПАКЕТЫ

Исходные кадры и разметка остаются в training\dataset.
Новые варианты сохраняются отдельно в training\dataset_augmented.
Проверочные кадры (val) не изменяются и не участвуют в создании вариантов.

Что меняется

Цвет, яркость и контраст; размер и положение сцены; отражение по горизонтали.
Дополнительные изменения имитируют условия камеры. Точные применённые
преобразования записаны для каждого кадра в manifest.json и train.json.
Рамки всех объектов меняются вместе с изображением; их категории сохраняются.
Геометрия сохраняет все метки и не допускает исчезновения объекта: остаётся
не менее 60% его площади и достаточно крупная рамка.

Для кадров с мешком/пакетом создаётся 6 дополнительных вариантов, для остальных
кадров — 2. Профиль bag_focus также делает изменения таких кадров разнообразнее.
Обычные цветовые изменения относятся ко всему кадру. Дополнительно зелёную
ткань мешка можно перекрашивать отдельно там, где подготовлена и проверена
маска его ткани. Маски берутся из training\bag_color_masks\manifest.json;
они привязаны к конкретному исходному изображению и проверяются по SHA.
Руки, деньги, фон и клетчатые мешки не следует включать в такую маску.
Если проверенной маски нет, используется только изменение цвета всего кадра.
Перемещение и масштаб тоже относятся к сцене с объектами, а не к вырезанному мешку.

Посмотреть результат

Откройте training\dataset_augmented\preview.jpg — исходники рядом с вариантами,
с рамками объектов. В gallery.html можно открыть изображения крупнее и прочитать
параметры. В manifest.json находятся количества, seed, контрольные суммы и
проверки, что train и val разделены по исходным видео.

Повторить экспорт (PowerShell, из D:\open\case)

  python augment_dataset.py --output training\dataset_augmented_new --seed 20261017

Тот же seed и тот же исходный набор дают те же варианты при той же версии кода
и библиотек. Непустая папка не перезаписывается: для нового экспорта укажите
другое имя. Экспорт работает на процессоре и сам по себе не обучает модель.

Обучение: выберите один способ

1. Исходная выборка с новыми случайными вариантами на каждой эпохе:

  python train_objects.py --augmentation bag_focus --output training\rtdetr_aug_new

   Исходные train/val используются по умолчанию. Валидация всегда без аугментации.
   Можно продолжить от ранее обученных весов, добавив:

  --weights training\rtdetr_custom_final\best.pth

2. Если нужен именно сохранённый набор из training\dataset_augmented:

  python train_objects.py --train training\dataset_augmented\train.json --val training\dataset_augmented\val.json --images-root training\dataset_augmented --augmentation none --output training\rtdetr_aug_static_new

   Параметр --augmentation none нужен, чтобы не накладывать сильные случайные
   преобразования поверх уже сохранённых вариантов.

Проверить сохранённую разметку без обучения

  python train_objects.py --train training\dataset_augmented\train.json --val training\dataset_augmented\val.json --images-root training\dataset_augmented --check-data

Границы результата

Варианты помогают обучению, но не заменяют новые реальные примеры мешков,
ракурсов и помещений. Они не доказывают улучшение: это проверяется сравнением
моделей на одинаковой неизменённой выборке. Создание вариантов не меняет текущие
веса веб-приложения автоматически и не добавляет определение денег внутри мешка.
