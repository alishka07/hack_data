Локальная модель для сейфа, счётчика банкнот, ноутбука и пакета

Рабочая папка: D:\open\case
Используется тот же глобальный Python, что и раньше; отдельное окружение не нужно.
Видео обрабатываются локально. Для запуска готовых весов интернет не требуется.

1. Откройте терминал и перейдите в рабочую папку:

   cd D:\open\case

2. Запустите обученную модель на одном видео:

   python start.py --trained --video X-17.mov

   В Jupyter с вашим глобальным kernel выполните в отдельной ячейке:

   %cd D:\open\case
   %run start.py --trained --video X-17.mov

   По умолчанию анализируется один кадр в секунду. Можно указать полное имя
   файла или полный путь к нему. Запись X-17 распознаётся и для файла Х-17.mov
   с русской буквой «Х».

3. Проверьте все видео с шагом 5 секунд:

   python start.py --trained --all --interval 5

Результат: results\trained_objects\index.html. Откройте этот файл в браузере.
В папках отдельных видео сохраняются размеченное видео, кадры и таблицы.
Содержимое между проверенными кадрами может остаться незамеченным: шаг 5 секунд
не подходит для проверки правила «дверь открыта 3,5 секунды».

По умолчанию используются веса:
   training\rtdetr_custom_final\best.pth

Если рядом есть calibration.json, программа применяет записанные пороги для
каждого класса и проверяет, что они относятся к этим весам. Общий порог можно
явно заменить, например:

   python start.py --trained --video X-17.mov --threshold 0.4

Без --trained запускается прежний вариант с Grounding DINO.

ЧТО ИМЕННО ОБУЧЕНО

Классы: safe — сейф; banknote_counter — счётчик банкнот; laptop — ноутбук;
bag — пакет или сумка, которую держит человек либо которая лежит на столе.
Сложенный пакет тоже относится к bag. Ограничение по размеру A4 не применяется.
Модель не определяет наличие денег внутри пакета.

Разметку 51 кадра подготовил AI-ассистент после визуального просмотра:
35 кадров для обучения, 16 для проверки. Пользователь подтвердил, что серый
металлический объект — сейф. Видеоролики разделены
целиком, соседние кадры одного ролика не попадают в обе части. Примеры пакетов
найдены в Х-13, Х-14, Х-15, Х-16, Х-17 и Х-40. Бежевое пальто в Х-40 оставлено
одеждой; пакет в этой сцене — отдельная клетчатая сумка с чёрными ручками.
Пакеты в руках и на столе включены в разметку; отдельной проверки взаимного
положения рук, стола и пакета пока нет.

Это дообучение RT-DETRv2 на небольшой постановочной выборке. Первоначальный
запуск завершил 4 эпохи до нехватки видеопамяти. Финальный запуск использует
полученные веса как начальные и выполняет ещё 12 эпох с заново созданным
оптимизатором. Это не непрерывное возобновление прежнего состояния обучения.

Результаты проверки на этой небольшой выборке не доказывают качество на новых
камерах, других сейфах или иных пакетах. Сейф обучается как отдельный объект;
наличие любого замка само по себе не превращает предмет в сейф. Это поиск
объектов, а не готовая автоматическая проверка всех банковских нарушений.

ЕСЛИ НУЖНО ЗАНОВО ОБУЧИТЬ

Сначала можно проверить разметку без запуска обучения:

   python train_objects.py --check-data

Новый запуск в отдельную папку, не заменяя готовые веса:

   python train_objects.py --epochs 12 --output training\rtdetr_custom_new

Параметры по умолчанию: размер изображения 384, пакет из 1 изображения,
queries=80, denoising=10. Если папка уже использовалась
для обучения, выберите другое имя. Существующий результат не перезаписывается
без отдельного параметра --overwrite.

Запуск новых весов:

   python start.py --trained --video X-17.mov --weights training\rtdetr_custom_new\best.pth

Новые веса могут требовать новых порогов. Если calibration.json отсутствует,
программа сообщает об этом и использует общий порог 0.35.
