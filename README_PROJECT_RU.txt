ПРОВЕРКА ВИДЕО КАССЫ — ИСХОДНЫЙ КОД

Проект анализирует записи локально: объекты кассы, людей и перемещения,
визуальные состояния, а затем формирует возможные события для проверки.
Рамки предметов и траектории не подтверждают нарушение сами по себе.

ЗАПУСК В ПОДГОТОВЛЕННОМ ОКРУЖЕНИИ
  python launch_web.py
  http://127.0.0.1:8765/
  http://127.0.0.1:8765/annotations

Используется глобальный Python 3.11. requirements-web.txt содержит только
зависимости веб-интерфейса. Для полного ML-пайплайна нужны уже подготовленные
Torch/CUDA, OpenCV, Transformers и зависимости соответствующих моделей.

ТЕКУЩЕЕ РАЗМЕЩЕНИЕ ЗАВИСИМОСТЕЙ
  open/
    case/                   этот проект
    RT-DETR-main/            RT-DETRv2, код и исходные веса
    GroundingDINO-local/     локальный detect_local.py и weights/

Официальные исходники моделей:
  https://github.com/lyuwenyu/RT-DETR
  https://github.com/IDEA-Research/GroundingDINO

Локальные адаптеры отличаются от чистых upstream-репозиториев. Одного клона
этого проекта на новый компьютер недостаточно для полного анализа видео.
Для переноса нужны также перечисленные зависимости, веса и разрешённые данные.

ПИЛОТ ДЕТЕКТОРА БАНКНОТ
Выполнено 40 эпох обучения отдельного cash-only RT-DETRv2 на области стола.
15 кадров обучения / 5 кадров выбора порога / 8 отложенных кадров.
Видео разделены по SHA-256, включая одинаковые файлы под разными именами.
Это предварительная разметка ассистента в одной комнате; не независимый
человеческий эталон и не измерение качества обнаружения нарушений.

На 6 размеченных пачках в отложенных кадрах, с заранее выбранными порогами:
  RT-DETR ROI:             найдено 1, пропущено 5, ложных рамок 0
  Grounding DINO весь кадр: найдено 6, пропущено 0, ложных рамок 2
  Grounding DINO ROI:      найдено 4, пропущено 2, ложных рамок 1
Новый cash-only детектор НЕ подключён по умолчанию: результат хуже исходного.
Код эксперимента: prepare_cash_pilot.py, train_objects.py,
evaluate_cash_pilot.py, cash_pilot_report.py, detect_cash_roi.py.
Оценка не использует шаблоны ответов или ручные коррекции при предсказании.

ПРОВЕРКИ
  python -m unittest discover -s . -p "test_*.py"
На момент подготовки: 454 теста полного набора прошли; затем 9 целевых тестов
проверили финальные изменения запуска экспериментальной cash-модели.

ПРАВИЛА И ОГРАНИЧЕНИЯ
Пользовательский порог открытой двери: 3,5 секунды. Это настройка кейса,
а не утверждение о требовании НБРК. Закрытая дверца не доказывает запирания.
Содержимое мешка, подлинность карточки, принадлежность документов и завершение
банковской операции не определяются по наличию рамки предмета.
Ручные уточнения и предложения ассистента хранятся с разным происхождением.
Дополнительная плотная проверка Grounding DINO по умолчанию выключена из-за
высокой стоимости обработки; включается только явно CASE_ENABLE_DENSE_REVIEW=1.
