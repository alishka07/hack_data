FORTE — ПРОВЕРКА РАБОТЫ КАССЫ ПО ВИДЕО

АКТУАЛЬНОСТЬ
Ручной просмотр кассовых записей занимает время, а короткие нарушения легко
пропустить. Forte выделяет эпизоды для проверки и связывает выводы с кадрами.

ЧТО ДЕЛАЕТ
• Анализ MOV: люди, предметы, рабочие зоны и события с наличными,
  личными вещами, уходом кассира и оставленным включённым экраном.
  Есть автоматические и ручные пункты проверки.
• Результаты: статусы, оценка модели, обоснование и кадры; повторы
  объединяются в интервалы, спорные случаи показываются первыми.
• Просмотр: видео, шкала событий, переход по времени, фрагмент ±3 секунды,
  рамки найденных объектов.
• Проверяющий: подтверждение/отклонение, комментарии, исправление времени,
  добавление пропущенных событий и сохранение решений.
• История, поиск, фильтры и показатели качества по проверенной разметке.
• Отчёт: один HTML-файл с кадрами и решениями, открывается в браузере.
• Сайт и API; русский/английский; компьютер и телефон.

Проценты — некалиброванные оценки модели. «Нет оценки» не означает 0%.
Окончательный вывод делает проверяющий.

КАК РАБОТАЕТ
Видео → кадры → люди, предметы и зоны → проверка событий → правила → отчёт.

API и задания: Python, FastAPI, SQLite.
Видео: FFmpeg, OpenCV.
Люди, позы и предметы: YOLOX-nano, ByteTrack, RTMPose, OWLv2.
Проверка событий: Qwen3-VL-4B (4-битная модель), llama.cpp, GPU.
Интерфейс: HTML, CSS, JavaScript.

КАК ЗАПУСТИТЬ
Установка не нужна. Откройте сайт → введите ключ от команды → выберите
.mov → нажмите «Анализировать видео». Отчёт скачивается в конце результатов.

Сайт:
https://belt-fifty-moreover-situation.trycloudflare.com/

API base URL:
https://belt-fifty-moreover-situation.trycloudflare.com/api/v1

Ключ API команда передаёт отдельно.
POST /api/v1/analyze — загрузка, multipart-поле file.
GET /api/v1/jobs/{job_id} — статус и результат.
Заголовок обоих запросов: X-API-Key.

Условия демо: MOV до 95 МБ, один анализ за раз. Ссылка временная,
работает при включённом сервере команды и меняется при перезапуске туннеля.

Запуск на своём компьютере: docs/local-setup.md.
Подробная техническая документация: README_TECHNICAL.md.
