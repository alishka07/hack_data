Forte — инструкция для жюри
==========================

Проект помогает проверять видеозаписи работы кассы: отмечает возможные
нарушения, показывает время события, наблюдаемое действие и кадры для проверки.
Окончательное решение принимает проверяющий после просмотра доказательств.

Для проверки через сайт достаточно браузера и ключа API. Скачивать проект,
устанавливать Python или иметь видеокарту на своём компьютере не нужно.


1. Как открыть демонстрацию

Сайт:
https://belt-fifty-moreover-situation.trycloudflare.com/

Ключ API команда проекта передаёт жюри отдельно вместе со ссылкой.
В открытом репозитории ключ не публикуется.

Это временный демонстрационный адрес. Если сайт не открывается, обратитесь
к команде за актуальной ссылкой: после перезапуска туннеля адрес меняется.
Для работы демонстрации компьютер команды и сервер должны оставаться онлайн.


2. Как загрузить видео

1) Откройте сайт. Справа вверху можно выбрать «Русский» или «English».
2) Вставьте полученный ключ в поле «Ключ API».
3) Дождитесь надписи «Обработчик готов».
4) Нажмите «Выбрать видео» или на пустую область предпросмотра.
   Также можно перетащить файл в область загрузки.
5) Выберите видео в формате .mov размером до 95 МБ.
6) Нажмите «Анализировать видео» и дождитесь результата.

Одновременно обрабатывается одно видео. Если показано «Идёт анализ»,
дождитесь завершения текущей проверки. Обработка занимает время.
При неполном анализе система показывает ограничения и случаи для проверки.

Для повторного открытия результата используйте «История анализов»
или «Открыть анализ по ID». После обновления страницы ключ нужно ввести снова.
Жюри с общим ключом видит общую историю демонстрации и решения проверяющих.


3. Как читать результаты

В таблице указаны проверка, результат, оценка модели и время события.
Случаи со статусом «Требует проверки» показываются первыми.
Нажмите на время или отметку на шкале, чтобы перейти к нужному моменту видео.
Откройте подробности и сравните обоснование с исходными кадрами.

Что означают статусы:

- «Подтверждено моделью» — модель нашла признаки, удовлетворяющие условиям
  данной проверки. Проверяющий должен сверить их с видео.
- «Требует проверки» — наблюдение есть, но для вывода нужен просмотр человеком.
- «Не подтвердилось» — модель отклонила конкретную проверку по доступным данным.
- «Недостаточно данных» — видимость или контекст не позволяют сделать вывод.

«Нет оценки» означает, что числовая оценка недоступна. Это не 0%.
Проценты являются приблизительными, некалиброванными оценками модели.
Оценка видимого действия сама по себе не подтверждает нарушение целиком.
Отсутствие подтверждённых находок не гарантирует отсутствия всех нарушений.

«Обоснование» кратко описывает наблюдаемое действие. Повторные наблюдения
могут объединяться в один интервал; он не доказывает, что предмет или действие
непрерывно присутствовали между всеми указанными моментами.


4. Как проверить вывод и сохранить отчёт

1) Посмотрите предложенный фрагмент и кадры, прочитайте обоснование.
2) При необходимости укажите решение: «Подтвердить», «Отклонить»
   или «Недостаточно данных». Можно уточнить время и добавить комментарий.
3) Укажите имя проверяющего и сохраните внесённые изменения.
4) В конце результатов откройте блок «Отчёт по анализу».
5) Если есть несохранённые правки, нажмите «Сохранить изменения».
6) Нажмите «Скачать отчёт · HTML».

Отчёт сохраняется одним HTML-файлом с результатами, решениями проверяющего
и кадрами. Его можно открыть в браузере без интернета. Исходное видео
целиком в отчёт не включается.


5. Если что-то не работает

- Неверный ключ: скопируйте ключ, полученный от команды, без лишних пробелов.
- Обработчик недоступен: подождите или сообщите команде.
- Очередь занята: дождитесь завершения текущего анализа и повторите загрузку.
- Файл отклонён: проверьте формат .mov, размер до 95 МБ и воспроизведение видео.
- «Не удалось завершить анализ»: откройте сообщение об ошибке. Такой результат
  не означает, что нарушений нет. При повторной ошибке передайте команде ID анализа.
- Кнопка скачивания отчёта недоступна: дождитесь завершения анализа
  и сохранения изменений.


6. API для автоматизированной проверки (необязательно)

При работе только через сайт этот раздел можно пропустить.

Базовый адрес API:
https://belt-fifty-moreover-situation.trycloudflare.com/api/v1

В каждом запросе загрузки или получения результата передавайте заголовок:
X-API-Key: ВАШ_КЛЮЧ_ОТ_КОМАНДЫ

Загрузить видео:
POST <базовый адрес API>/analyze
Тело запроса: multipart/form-data, поле file содержит файл .mov.
Успешное принятие: HTTP 202 и JSON {"job_id":"идентификатор"}.

Получить результат:
GET <базовый адрес API>/jobs/<job_id>
Статус processing — обработка продолжается; done — результат сформирован;
failed — анализ не завершён, готового вердикта нет.
Повторяйте запрос статуса с паузой, например раз в 3–5 секунд.

При done ответ содержит verdict и список violations с типом проверки,
временем, описанием и кадрами. verdict=violation означает наличие
подтверждённой моделью находки; no_violation — таких находок нет
в проверенной области. Полноту проверки и ограничения смотрите в интерфейсе.

Частые HTTP-коды: 401 — неверный ключ; 413 — слишком большой файл;
415 — неподдерживаемый формат; 429 — сервис занят; 503 — обработчик не готов.
При 429/503 учитывайте заголовок Retry-After.

Инструкция для запуска проекта на другом компьютере: docs/local-setup.md.
